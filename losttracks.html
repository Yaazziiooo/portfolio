01 / The Game

A Town Without Music

Players can recover R&B, rock and pop tracks through challenges around the town. The collected music and other items are used to complete quests for its residents.

I created Lost Tracks as my specialization project at Futuregames, developing the gameplay, interactions, UI and progression in C#.

03 / My Work

What I Built

01 / QUESTS & PROGRESSION

Quest System

I built a QuestManager for three questlines: the club, supermarket and school. It handles objectives, item deliveries and quest progression as players complete challenges.

02 / GAMEPLAY PROGRAMMING

Three Music Challenges

I programmed three music minigames: Timing, Note Collection and Memory. Each has its own gameplay mechanics and completion conditions, with results passed back to the quest system to update player progression.

03 / INTERACTION

NPCs & Dialogue

I programmed NPC interactions with a dialogue system that displays conversations and lets players start music challenges. The dialogue UI works alongside the quest system to support player progression.

04 / INVENTORY

Items & Music Tracks

I built an inventory system that tracks collected music tracks and items. NPC interactions check the inventory when players deliver requested items, and QuestManager updates their progress.

05 / UI PROGRAMMING

ActionStack Menus

I built a stack-based UI system to manage transitions between gameplay, pause, settings and the main menu. It keeps track of the previous screen so players can return without losing their place.

06 / AUDIO

Music & Transitions

I implemented an audio system that manages music playback and smooth transitions between exploration and minigames. Music fades out when entering a challenge and fades back in when returning to exploration.

07 / SYSTEMS

Gameplay Communication

I used C# events to connect the gameplay systems. When a player completes a minigame or delivers an item, the relevant systems are notified so quest progression and UI can update.

04 / Behind the Code

Connecting Challenges to Quests

QuestManager listens for challenge completion events. When a minigame is completed, it checks active quests for the matching objective and updates that objective.

The quest update event then notifies other systems, including the quest UI.

private void OnEnable()
{
    if (challengeCompletedEvent != null)
        challengeCompletedEvent.OnRaised += HandleChallengeCompleted;
}

private void OnDisable()
{
    if (challengeCompletedEvent != null)
        challengeCompletedEvent.OnRaised -= HandleChallengeCompleted;
}

private void HandleChallengeCompleted(ChallengeType challengeType)
{
    foreach (Quest quest in activeQuests)
    {
        if (quest.state != QuestState.Active) continue;

        foreach (QuestObjective objective in quest.objectives)
        {
            if (objective.type == ObjectiveType.CompleteChallenge &&
                !objective.isCompleted &&
                objective.requiredChallenge == challengeType)
            {
                objective.isCompleted = true;
                questUpdatedEvent?.Raise(quest);
                break;
            }
        }

        CheckQuestCompletion(quest);
    }
}

NPCs with Their Own Quest States

Each NPC uses a six-state system to manage conversations, music requests, item deliveries and quest completion.

The NPC checks what the player has collected, responds with the appropriate dialogue and updates the quest when a requested track or item is delivered.

// Selected method from NPC.cs
private void HandleInteraction(GameObject interactor)
{
    if (dialogueUI == null) return;

    Inventory inventory = interactor.GetComponent<Inventory>();

    if (inventory == null) return;

    switch (npcState)
    {
        case NPCState.Idle:

            dialogueUI.Show(introText);

            npcState = NPCState.AskedForTrack;

            break;

        case NPCState.AskedForTrack:

            dialogueUI.Show(trackRequestText);

            npcState = NPCState.WaitingForTrack;

            break;

        case NPCState.WaitingForTrack:

            if (inventory.HasTrack(requestedTrack))
            {
                inventory.RemoveTrack(requestedTrack);

                dialogueUI.Show(trackSuccessText);

                questManager.CompleteObjective(quest, 1);

                animator.SetBool("isTalking", false);
                animator.SetTrigger("isDancing");

                AudioManager.Instance?.PlaySFX(deliverySound);

                npcState = NPCState.AskedForItem;
            }
            else
            {
                dialogueUI.Show(trackRequestText);
            }

            break;

        case NPCState.AskedForItem:

            dialogueUI.Show(itemRequestText);

            npcState = NPCState.WaitingForItem;

            break;

        case NPCState.WaitingForItem:

            int amount = inventory.GetItemCount(requestedItem);

            if (amount >= requiredItemAmount)
            {
                for (int i = 0; i < requiredItemAmount; i++)
                {
                    inventory.RemoveItem(requestedItem);
                }

                dialogueUI.Show(itemSuccessText);

                questManager.HandleItemDelivered(
                    quest,
                    requestedItem,
                    requiredItemAmount);

                AudioManager.Instance?.PlaySFX(deliverySound);

                npcState = NPCState.Completed;
            }
            else
            {
                dialogueUI.Show(itemRequestText);
            }

            break;

        case NPCState.Completed:

            dialogueUI.Show(completedText);

            break;
    }
}
