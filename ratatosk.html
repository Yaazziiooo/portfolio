Ratatosk

UI Programmer · Unity · C#

About the Game

Ratatosk is a game where players collect nuts while avoiding obstacles and enemies, including trees and hostile squirrels.

The game features two modes: Chill and Thrill, offering different gameplay experiences.

Gameplay Trailer

My Contributions

As one of four programmers on the team, I was primarily responsible for UI implementation and also contributed to the game's day-to-night cycle.

UI and Menu Systems

Implemented interactive menus using Unity's Canvas and UI Button components, including navigation and gameplay-related interface functionality.

Score-Based End Screens

Developed UI logic that displays different ending visuals based on the player's final score, using separate score ranges.

Game Over Interface

Implemented the Game Over interface for Thrill Mode, including Play Again and Main Menu buttons.

Audio Settings

Connected Unity's Audio Mixer to UI sliders, allowing players to adjust music and sound effects volume through the settings menu.

Day-to-Night Cycle

Contributed to a time-based lighting system that transitions between day and night, supporting the game's atmosphere and end-of-game sequence.

Technical Highlights

Audio Mixer Integration

One of my technical challenges was learning how to integrate Unity's Audio Mixer with UI controls.

I implemented slider-based volume adjustments for different audio categories, allowing players to configure the sound through the settings interface.

Gameplay and UI Synchronization

The day-to-night cycle also required coordination between lighting changes and gameplay timing.

I contributed to implementing the cycle and resolving timing issues around the end-of-game transition, helping create a smoother experience instead of an abrupt ending.
