Game Project

Ratatosk

Team of 9 3 weeks Unity C#

Collect nuts, dodge obstacles and watch out for hostile squirrels in Ratatosk. Choose between Chill and Thrill modes for two different ways to play.

Explore my work ↓ Watch gameplay ↓
01 / The Game

Gameplay

See Ratatosk in action, including its environments, obstacles and different gameplay modes.

02 / My Work

What I Built

As one of four programmers on the team, my main focus was UI implementation. I also worked on audio settings and the game's day-to-night cycle.

01 / UI PROGRAMMING

UI and Menu Systems

Built the game's menus using Unity UI, handling button interactions, navigation between screens and gameplay-related interface functionality.

02 / GAMEPLAY UI

Score-Based End Screens & Game Over

Built a score-based ending system that displays different end screens depending on the player's final score. In Thrill Mode, the Game Over screen also lets players restart or return to the main menu.

03 / AUDIO

Audio Settings

Integrated Unity's Audio Mixer with volume sliders in the settings menu, allowing players to adjust music and sound effects separately.

04 / GAME SYSTEMS

Day-to-Night Cycle

Worked on the day-to-night cycle, synchronizing lighting changes with gameplay timing to create a smoother transition into the end-of-game sequence.

Tools & Systems
