Ok'Rhams Creation

UI Programmer · Unreal Engine 5 · Blueprints

About the Game

Ok'Rhams Creation is a first-person puzzle-action game set inside a dark and mysterious cathedral.

Players explore the environment, collect artifacts, avoid dangers and activate ancient systems to progress through the game.

Gameplay Trailer

My Contributions

I was responsible for implementing the game's entire user interface using Unreal Engine 5 Blueprints, including menus, interaction prompts, inventory feedback and gameplay UI.

Interaction Prompt System

Implemented a trigger-based interaction system that displays contextual prompts when players approach interactable objects.

Menu Systems

Built the main menu, pause menu and death menu using Blueprint, including button functionality and game state transitions.

Input and Cursor Handling

Implemented input mode switching and mouse cursor visibility to support navigation between menus and gameplay.

Inventory Feedback

Connected inventory-related gameplay events to UI updates, providing visual feedback when players interacted with or collected objects.

Reusable Blueprint Events

Structured UI logic using reusable Blueprint events and configurable variables, allowing other developers to trigger interface updates from their systems.

Technical Highlights

Blueprint-Based UI Architecture

All UI functionality was implemented using Unreal Engine's visual scripting system rather than C++.

I used Blueprint nodes such as Create Widget, Add to Viewport, Set Visibility and Remove from Parent to manage interface creation, updates and removal.

Gameplay and UI Integration

Interaction prompts were activated through trigger volumes, allowing UI elements to respond to player proximity and gameplay events.

I also worked with input modes and mouse cursor control to make transitions between menus and gameplay function correctly.

Modular UI Design

I exposed reusable Blueprint events so that other team members could connect their gameplay systems to the UI without modifying the underlying interface logic.
