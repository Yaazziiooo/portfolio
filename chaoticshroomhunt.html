Chaotic Shroom Hunt

Game Programmer · Unreal Engine 5 · C++

UNREAL ENGINE 5 · C++ Chaotic Shroom Hunt GAMEPLAY & SYSTEMS PROGRAMMING

About the Game

Chaotic Shroom Hunt is a third-person arcade game where players control a dragon and collect mushrooms while avoiding traps and hazards.

The game features five levels with increasing difficulty, different pickup types and a time-limited scoring system.

Developed in Unreal Engine 5 using C++, the project focuses on gameplay systems, level progression and reusable game architecture.

My Contributions

I developed the core gameplay systems, including spawning, game states, scoring, health, timers and menu navigation.

Gameplay Systems

Implemented scoring, health and timed gameplay, including level progression and win/loss conditions.

Spawn Manager & Pooling

Developed a spawn manager using reusable actor pools for mushrooms and other gameplay objects, reducing repeated spawning and destruction.

ActionStack Architecture

Implemented a stack-based system for managing menu and gameplay states, including Main Menu, Gameplay, Pause, Game Over and Level Complete.

Level Progression

Developed logic for five levels with increasing score requirements, difficulty and gameplay challenges.

Gameplay HUD

Implemented UI elements for health, score and remaining time, including damage feedback and countdown effects.

Audio & Settings

Implemented gameplay audio feedback and settings functionality, including volume control.

Technical Highlights

Object Pooling

The spawning system reuses gameplay actors instead of continuously creating and destroying them. This helps reduce runtime overhead.

Stack-Based Game States

I implemented an ActionStack architecture to separate gameplay logic from menu navigation and state transitions.

Level Progression

The game uses a level-based progression system with increasing difficulty and gameplay challenges.
